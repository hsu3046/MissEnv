# MissEnv

프로젝트마다 흩어진 `.env` 파일을 한곳에서 찾고, 비교하고, 편집하는 개인용 macOS 앱.

SwiftUI + AppKit으로 만들었습니다. 서버, 계정, 암호화 저장소, 외부 패키지 의존성이 없습니다. 환경변수 값은 기존 파일에서 직접 읽고 쓰며, 등록 목록에는 폴더 정보만 저장합니다.

## 실행

macOS 14 이상, Xcode의 Swift 6 도구가 필요합니다. 이 개발 환경에서는 macOS 27 / Xcode 27 / Apple Silicon으로 검증했습니다.

```bash
git clone https://github.com/hsu3046/MissEnv.git
cd MissEnv
./scripts/run.sh
```

생성된 `build/MissEnv.app`을 직접 열거나 Applications 폴더에 복사해 사용할 수 있습니다. 로컬 빌드는 ad-hoc 서명이며, 배포용 Developer ID 서명·공증은 포함하지 않습니다.

## 사용

오른쪽 위 **톱니바퀴** 또는 **⌘,**에서 설정·사용 설명서·앱 정보와 제작사 링크를 확인할 수 있습니다.

1. **폴더 등록** 또는 `⌘O`로 폴더를 선택합니다. 여러 폴더를 한 번에 등록할 수 있고, 하위 폴더도 탐색합니다.
2. 사이드바에서 `.env` 파일을 선택합니다. 변수 행을 선택하면 값·주석·다른 파일의 선언 여부가 나옵니다.
3. **편집** 또는 행을 더블 클릭해 값을 수정합니다. **변수 추가** 및 삭제도 지원합니다.
4. **원본** 탭에서 파일 전체를 편집할 수 있습니다. **비교** 탭에서는 `.env.example` 등과 누락·추가·값 차이를 확인합니다.
5. **변경 저장** 또는 `⌘S`로 변경 행을 확인한 뒤 원본에 반영합니다.

`.env.example` 등 이름에 `example` 구분자가 있는 예제 파일은 기본적으로 제외합니다. **설정 (`⌘,`) → example 파일 포함**을 켜면 목록·집계·검색·비교에 다시 포함되며, 설정은 다음 실행에도 유지됩니다. 편집 중인 예제 파일을 제외할 때는 저장·취소 여부를 먼저 확인합니다.

**전체 프로젝트 → 전체 환경변수**에서 변수명별 프로젝트 수와 값의 종류를 확인하세요. **2개 이상 프로젝트에서 사용 / 같은 이름, 다른 값 / 값 없음 또는 공백**으로 좁히고, 펼친 값의 사용처를 선택하면 해당 파일의 정확한 변수를 인라인 편집합니다. **중복되는 값** 보기는 이름이 달라도 같은 값을 사용하는 프로젝트를 찾습니다. 이 보기에서만 빈 값·숫자·true/false 등 일반 값은 제외합니다. 프로젝트 간 값 차이는 오류로 간주하지 않습니다.

상단 검색은 전체 등록 프로젝트의 **변수명**을 검색합니다. 탐색 폴더는 사이드바 하단에서 등록 해제하며 원본 파일은 삭제하지 않습니다.

프로젝트 수는 등록 폴더 안의 Git·프로젝트 설정 파일(Xcode 포함)을 기준으로 셉니다. 현재 필터에서 표시할 `.env` 파일이 있는 프로젝트만 표시·집계하며, 설정 파일이 없으면 `.env`를 담은 폴더를 프로젝트로 묶습니다. 중첩 프로젝트는 별도로 표시하고, 겹치는 탐색 폴더는 중복 집계하지 않습니다.

## 파일 보호

- 변수 편집은 원본의 정확한 범위만 교체합니다. 주석·공백·줄 순서·`export`·UTF-8 BOM·LF/CRLF를 보존합니다.
- 중복 선언은 합치지 않고 각각 표시합니다. 같은 변수명·같은 값의 반복은 정보로 표시하고, 같은 변수명에 서로 다른 값이 있으면 경고합니다. 서로 다른 변수의 `true`·`false` 등 같은 값은 경고하지 않습니다. 비교는 마지막 선언을 기준으로 합니다.
- 저장 직전 원본 바이트를 대조합니다. 외부 변경을 감지하면 덮어쓰기를 차단합니다.
- 변경 감지는 현재 열린 파일을 3초 간격 및 앱 활성화 시 확인합니다. 미저장 내용은 자동으로 다시 불러오지 않습니다.
- 매 저장 전 원본을 같은 디렉터리의 `.MissEnvBackups`에 백업합니다. 백업은 일반 파일이며 자동 삭제하지 않습니다.
- 저장은 같은 볼륨의 임시 파일과 원자적 교체를 사용하고 기존 POSIX 권한을 보존합니다.
- 심볼릭 링크, UTF-8이 아닌 파일, 2MB를 넘는 파일은 편집하지 않습니다.
- 변수 확장·셸 실행·환경변수 주입은 수행하지 않습니다. 파일의 구문 그대로 비교·편집합니다.

**백업 폴더도 실제 값을 포함합니다.** 저장소에 `.MissEnvBackups/`를 gitignore로 추가하세요. 백업이 많아지면 필요한 파일을 보관하고 직접 정리할 수 있습니다.

## 개발·검증

```bash
swift test
./scripts/build.sh
./scripts/demo.sh  # 가짜 값으로 만든 데모; 실제 프로젝트 목록과 분리
```

Xcode에서 `Package.swift`를 열어 소스를 편집할 수 있습니다. `.app` 패키징은 위 빌드 스크립트를 사용합니다.
