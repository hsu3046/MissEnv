# Privacy Policy / 개인정보 처리 안내

Last updated: 2026-10-03 · Developer: AIB Inc. (https://www.aib.vote)

MissEnv is a local macOS environment-file manager. It does not require an account and has no developer-operated server, analytics, advertising, or telemetry. It does not collect or transmit your environment-file contents, variable names, values, project paths, or usage data to AIB Inc. or third parties.

Files are read from folders you explicitly select and edited locally. Folder registrations and access bookmarks are stored locally. Original environment files remain in place. Before saving, the previous file is backed up to `.MissEnvBackups` beside the original; these backups contain the original values and remain until you remove them. Clipboard copies use the operating system clipboard.

Company, documentation, support, and source-code links open external websites in your browser. Those websites operate under their own privacy policies. Information you voluntarily submit in a public GitHub issue is public; do not include real environment variables, credentials, or private file contents.

To remove local data, unregister folders in the app and remove any unneeded original files/backups through Finder. Unregistering a folder does not delete original files. No cloud account or cloud deletion request is needed. For support, use https://github.com/hsu3046/MissEnv/issues without including sensitive information.
