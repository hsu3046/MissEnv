# MissEnv 지원 · Support

MissEnv는 여러 프로젝트의 환경변수 파일을 검색하고 편집·비교하는 macOS 앱입니다.

## 문의 및 문제 신고

사용 방법에 관한 질문, 오류 신고, 기능 요청은 **[지원 요청 작성](https://github.com/hsu3046/MissEnv/issues/new)**에서 접수합니다. GitHub 계정으로 로그인한 뒤 제목과 내용을 작성하고 제출하세요. 답변은 해당 요청의 댓글에서 확인할 수 있습니다.

- 사용 방법: [사용 설명서](USER_GUIDE.md)
- 기존 문의 확인: [지원 요청 목록](https://github.com/hsu3046/MissEnv/issues)
- 개인정보 처리: [개인정보 안내](PRIVACY.md)

오류 신고에는 MissEnv 버전, macOS 버전, 문제를 재현하는 순서, 예상 결과와 실제 결과를 적어주세요. 화면 캡처는 선택 사항입니다. 지원 요청은 공개되므로 비밀번호, API 키, 실제 환경변수 값이나 개인 정보가 담긴 파일은 첨부하지 마세요. 예시는 가상 값으로 바꿔주세요.

## 자주 묻는 질문

**창을 닫았는데 다시 어떻게 여나요?**  
버전 0.1.0 빌드 2부터 메뉴의 **파일 → MissEnv 창 열기** 또는 **⌘N**으로 다시 열 수 있습니다.

**폴더를 등록해도 프로젝트가 보이지 않아요.**  
환경변수 파일이 있는 프로젝트만 표시합니다. 등록한 폴더 아래에 `.env` 또는 `.env.*` 파일이 있는지, 설정에서 예제 파일을 제외했는지 확인하세요.

**파일이 서버로 전송되나요?**  
환경변수 파일은 Mac에서 처리합니다. MissEnv는 환경변수 값을 서버에 전송하지 않습니다.

## English support

For questions, bug reports, or feature requests, **[open a support request](https://github.com/hsu3046/MissEnv/issues/new)**. Sign in to GitHub, describe your question, and submit it. Responses appear in the issue comments. Korean and English inquiries are welcome.

For bugs, include the app version, macOS version, steps to reproduce, and expected versus actual behavior. Requests are public: never include passwords, API keys, real environment variable values, or personal data. Use fictional examples instead.
