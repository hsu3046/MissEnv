# MissEnv 사용 설명서

## 시작하기

macOS 14 이상에서 사용할 수 있습니다. 오른쪽 위 **+** 또는 **⌘O**로 프로젝트 폴더나 상위 폴더를 등록하세요. 하위 폴더의 `.env`와 `.env.*`를 찾고, 환경변수 파일이 있는 실제 프로젝트만 표시합니다. 탐색 폴더 등록을 해제해도 원본은 삭제하지 않습니다.

## 전체 환경변수

**모든 변수**는 변수명별 목록입니다. 오른쪽에 서로 다른 프로젝트 수와 값의 종류가 표시됩니다. 펼치면 값별로 프로젝트·파일·행이 나오며, 사용처를 선택하면 해당 선언의 인라인 편집으로 이동합니다.

- **2개 이상 프로젝트에서 사용**: 같은 이름이 서로 다른 프로젝트에 있습니다. 값은 달라도 포함합니다. 같은 프로젝트의 여러 파일은 프로젝트 하나로 셉니다.
- **같은 이름, 다른 값**: 같은 이름에 값이 2종류 이상 있습니다. 한 프로젝트 내 파일 차이와 중복 선언도 포함합니다. 오류를 의미하지 않습니다.
- **값 없음 또는 공백**: 선언된 값 중 하나 이상이 없거나 공백뿐입니다. `KEY=`, `KEY=""`, `KEY=''`, `KEY=" "`가 해당하고 `0`, `false`는 제외합니다. 선언 자체가 없는 경우는 해당하지 않습니다.

필터 숫자는 서로 다른 변수명의 개수입니다. 바깥 따옴표만 다른 일반 값은 같은 값으로 묶지만, 이스케이프·확장 구문을 해석하거나 실행하지 않습니다.

**중복되는 값**은 서로 다른 프로젝트에서 이름이 달라도 같은 값을 사용하는 변수를 찾습니다. 이 보기에서만 빈 값·숫자·true/false·yes/no·on/off·null/nil/none/undefined를 제외합니다. 여러 파일을 한 번에 변경하는 기능은 제공하지 않습니다.

## 편집과 저장

사이드바의 환경 파일을 선택하고 변수를 고르세요. 연필 버튼, 행 더블 클릭으로 인라인 편집하고 **적용**을 누릅니다. **변수 추가**도 인라인으로 동작합니다. 복사·편집·삭제는 오른쪽 상세 화면의 아이콘을 사용하며, 삭제는 재확인합니다.

**변경 저장** 또는 **⌘S**를 누르고 변경 내용을 확인한 뒤 원본에 저장합니다. 적용만 누르면 편집 내용만 변경됩니다. 미저장 변경이 있으면 파일 전환과 종료 시 저장·버리기·취소를 선택할 수 있습니다. **원본** 탭은 파일 전체를 편집합니다.

## 비교

**비교** 탭에서 같은 프로젝트의 다른 환경 파일을 기준으로 선택합니다. 현재 파일과 기준 파일의 값 차이·한쪽에만 있는 변수를 보여줍니다. 비교는 읽기 전용이며 마지막 중복 선언을 기준으로 합니다. **동일한 값도 표시**로 같은 값까지 확인할 수 있습니다.

## 설정

오른쪽 위 톱니바퀴 또는 **⌘,**를 누릅니다. **설정**에서 example 파일 포함 여부를 바꾸고, **사용 설명서**와 **앱 정보**에서 안내·제작사·소스 코드·MIT 라이선스를 볼 수 있습니다.

`.env.example` 같은 예제 파일은 기본적으로 제외합니다. 옵션을 켜면 목록·검색·집계·비교에 포함되고 다음 실행에도 유지됩니다.

## 원본과 백업

저장 전 원본 바이트를 확인하며 다른 프로그램이 파일을 변경했다면 덮어쓰기를 차단합니다. 미저장 내용은 자동으로 다시 불러오지 않습니다.

매 저장 전 이전 원본은 같은 디렉터리의 `.MissEnvBackups`에 보관합니다. **백업에도 실제 값이 들어 있습니다.** 프로젝트의 `.gitignore`에 `.MissEnvBackups/`를 추가하세요. 백업은 자동 삭제하지 않습니다.

주석·공백·순서·export·UTF-8 BOM·줄바꿈을 보존합니다. UTF-8 파일만 지원하며 파일당 최대 2MB, 최대 탐색 깊이 12단계입니다. 심볼릭 링크와 의존성·빌드·백업 디렉터리는 탐색에서 제외합니다. 검색은 변수명 기준이며 **⌘R**로 목록을 갱신합니다.

## 단축키

| 단축키 | 기능 |
|---|---|
| ⌘N | MissEnv 창 열기 |
| ⌘O | 폴더 등록 |
| ⌘S | 변경 저장 |
| ⌘R | 목록 새로고침 |
| ⌘1 | 전체 프로젝트 |
| ⌘Z / ⇧⌘Z | 실행 취소 / 다시 실행 |
| ⌘, | 설정 |
